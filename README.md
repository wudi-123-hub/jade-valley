# 龙谷拾玉

《龙谷拾玉》是原创国风修仙游戏。玩家经营四季山门、推进主线，单人进入遗灯秘境。洛神和应龙开局可选。悟空、烛九阴、青龙、鸿钧、嫦娥、精卫、麒麟随宗门和远征进度解锁。选角页显示各自的解锁条件与招式。

## 本地运行

用 Godot 4.6.1 导入 `project.godot`，按 F5 运行。把 Windows 导出模板安装到编辑器后，可用项目自带的 `Windows Desktop` 预设打包。

## 横版即时斗法

从标题页进入「横版试炼」，可练习巡灯兽，也可直接挑战沉潭古甲。青龙谷新开启的远征会使用横版斗法，并结算远征奖励。

| 操作 | 键位 |
| --- | --- |
| 移动 | `A` `D` 或方向键 |
| 跳跃 | `Space` `W` 或 `↑` |
| 角色普攻、空中下击 | `J`，或按住 `S` 再按 `J` |
| 闪避 | `K` |
| 消耗三点剑意释放神技 | `L` |
| 携带时使用灵草 | `H` |
| 使用远征药剂 | `F` |
| 离开战场、切换全屏 | `Esc`、`F11` |

在灵药圃的「丹房备战」可消耗灵草和灵石炼制回春散、凝锋丸或镇煞符。每趟远征最多携带一份。主动撤回或破关时，库存会收回未用药剂。

新远征第四段可用本趟的 2 份灯砂挑战封灯獒。胜利后守关战伤害增加 9 点。击破灯门可额外带走 6 份灯砂，险途为 8 份。主动撤回时仅结算普通战利品。

获得首件镇门遗宝后，可在铭印台用 35 灵石和 5 灯砂领悟一种铭印。破势铭每场首次以神技打断时返还 1 点剑意。回息铭在赢下途中斗法后恢复至多 12 气血。已领悟的铭印可装配在任意已收录遗宝上，每趟选一种。

走完第三段可在归灯驿支付本趟的 8 灵石，选择寄存 1 至 3 份随身灯砂。每趟可寄一次，寄存灯砂在撤回、破关或败退时均会入账。封灯试炼的入场费从剩余的随身灯砂支付。

## 传道阁

走完远征第三段后主动撤回获得 1 张功法残页，破关获得 2 张。每名弟子可消耗 1 张残页选定一门主修。丹火诀弟子在丹房值守时，每日首炉省 1 株灵草。寻灯诀弟子在巡山时为新启程的远征筹措半程驿费，归灯驿仅收 4 灵石。派驻于次日生效。

首授功法解锁青龙，他的扇刃神技命中后返还 1 点剑意。嫦娥的月轮攻击命中可回复最多 14 气血。所有掌门可独立完成斗法。

## 美术

四季山门、剧情背景和秘境采用层叠云雾、暖金天光与青灰远山。角色保持 Q 版轮廓，战场的落脚边缘、敌招预警和地面阴影优先保证实战辨识度。
