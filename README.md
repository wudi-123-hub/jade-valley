# 龙谷拾玉

《龙谷拾玉》是原创国风修仙游戏。玩家操控小青团经营四季山门，推进主线，整备队伍进入遗灯秘境。

## 本地运行

用 Godot 4.6.1 导入 `project.godot`，按 F5 运行。把 Windows 导出模板安装到编辑器后，可用项目自带的 `Windows Desktop` 预设打包。

## 横版即时斗法

从标题页进入「横版试炼」，可练习巡灯兽，也可直接挑战沉潭古甲。青龙谷新开启的远征会使用横版斗法，并结算远征奖励。

| 操作 | 键位 |
| --- | --- |
| 移动 | `A` `D` 或方向键 |
| 跳跃 | `Space` `W` 或 `↑` |
| 斩击、空中下斩 | `J`，或按住 `S` 再按 `J` |
| 闪避 | `K` |
| 消耗三点剑意释放剑气 | `L` |
| 携带时使用灵草、灵契 | `H`、`Q` |
| 离开战场、切换全屏 | `Esc`、`F11` |

## 验证

```sh
godot --headless --path . -- --smoke
```

窗口回归场景为 `qa.tscn`。运行前将 `JADE_QA_OUT` 指向可写的临时目录，用于截图和隔离存档。
